# Software incluido

Esta copia contiene los dos proyectos usados por la tesis:

- `neuromorphic_lab/`: modelos de memristores, neuronas LIF, sinapsis, crossbar, configuraciones, validaciones y pruebas.
- `robot_sim/`: aplicaciones CartPole, visión, navegación y auto 2D, agentes REINFORCE/R-STDP, evaluadores y pruebas.

Los lanzadores `run_app.py` y `run_validation.py` están en esta carpeta. Para instalar dependencias usa `requirements.txt`; los comandos están en `../05_REPRODUCIR.md`.

`ENTREGA_MANIFEST_SHA256.json` registra hashes SHA-256 de los archivos fuente copiados el 28 de octubre de 2026. `outputs/` conserva algunos resultados existentes; las evidencias principales están separadas en `../03_EVIDENCIAS/`.

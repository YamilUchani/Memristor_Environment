# Software de la entrega

1. `neuromorphic_lab/` contiene el simulador general y sus validadores.
2. `robot_sim/` contiene los agentes y aplicaciones robóticas.
3. `run_app.py` abre la GUI de Neuromorphic Lab.
4. `run_validation.py` abre el lanzador de validaciones.
5. `requirements.txt` instala las dependencias combinadas.
